# CREVANTIQ DIRECTOR — Creator Web

A standalone Vite + React creator workspace preview.

## Run in GitHub Codespaces
```bash
cd creator-web
npm install
npm run dev
```
Open forwarded port **13001** (Vite binds to 0.0.0.0).

## Build
```bash
npm run build
```

## Scope and safety
- UI-only local preview. Forms and navigation are client-side demonstrations.
- No old backend, API, Supabase project, OAuth credentials, provider secrets, payment gateway, or external account integration is used.
- Plan prices and credit allowances are display-only placeholders pending approved commercial configuration.
- Plan selection does not charge, upgrade, or change a subscription.
- Social metrics are sample design figures, not live account data.
- AUTO publishing remains disabled; no content is published.
